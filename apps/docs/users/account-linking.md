# 기존 계정 연결

이미 동아리 회원으로 등록되어 있지만 SSO 계정은 아직 만들지 않은 분에게 안내되는 흐름입니다. 운영진이 보내준 **회원가입 링크에 `?code=...` 형태의 값이 붙어 있다면** 이 문서를 참고하세요.

```
https://auth.econovation.kr/sign-in?code=<영문/숫자로 구성된 코드>
```

## 사용 방법

1. 운영진이 보내준 링크를 **그대로** 클릭합니다. 링크 끝의 `?code=...` 부분은 매우 중요하므로 잘라내지 말고 그대로 사용해주세요.
2. 일반 회원가입 페이지와 똑같은 화면이 보입니다. **여기서 입력한 내용이 운영진이 미리 등록해둔 동아리 회원 정보와 자동으로 연결**됩니다.
3. 회원가입 양식을 채워 제출합니다. 입력 규칙은 [회원가입 안내](./sign-up)와 동일합니다.
4. 성공하면 자동 로그인되고 SSO 메인 페이지로 이동합니다.

> 화면상 일반 회원가입과 시각적인 차이는 거의 없습니다. 다만 백엔드에서 동아리 회원 정보(예: 기수, 활동 상태)와 연결되도록 처리되므로 **반드시 운영진이 안내해준 링크에서 시작해야** 합니다.

## 자주 묻는 사항

**Q. `code` 값은 직접 만들거나 추측해서 넣어도 되나요?**
A. 아니요. `code`는 동아리 운영진/시스템이 발급한 1회용 값입니다. 임의로 만든 값은 동작하지 않습니다.

**Q. 링크에 `?code=...`가 없으면 어떻게 되나요?**
A. 일반 회원가입과 동일하게 진행됩니다. 기존 동아리 정보와 자동 연결되지 않습니다.

**Q. 한 번 사용한 링크를 다시 사용할 수 있나요?**
A. 일반적으로 1회용으로 발급됩니다. 이미 가입을 완료했다면 같은 링크로 다시 가입할 수 없으며, 이후에는 일반 [로그인](./sign-in)을 이용하세요.

**Q. 링크를 클릭했더니 이상한 화면이 나옵니다.**
A. 링크가 만료되었거나 잘못 복사되었을 수 있습니다. 운영진에게 새 링크 발급을 요청해주세요.
