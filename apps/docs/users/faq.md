# 자주 묻는 질문

## 회원가입 / 로그인

**Q. 회원가입 페이지 주소가 왜 `/sign-in`인가요? 로그인 페이지 같은데…**
A. URL 경로가 약간 혼동되는 부분이 있습니다. 실제로는 다음과 같습니다.

| URL | 실제 화면 |
| --- | --- |
| `https://auth.econovation.kr` | 로그인 화면 |
| `https://auth.econovation.kr/sign-in` | **회원가입** 화면 |

**Q. 비밀번호 규칙이 까다로워요.**
A. 비밀번호는 다음 모두를 만족해야 합니다. 자세한 안내는 [회원가입 가이드](./sign-up#비밀번호-상세-규칙)를 참고하세요.

- 8자 이상 20자 이하
- 영문 · 숫자 · 특수기호 **각각 1개 이상** 포함
- 한글이나 공백은 사용할 수 없음

**Q. "이미 존재하는 계정입니다" 메시지가 나옵니다.**
A. 이미 같은 아이디로 가입된 계정이 있다는 뜻입니다. [로그인 페이지](./sign-in)에서 해당 아이디로 로그인을 시도해보세요. 비밀번호가 기억나지 않는 경우 운영진에게 문의해주세요.

## 비밀번호 분실

**Q. 비밀번호를 잊어버렸어요.**
A. 현재 시스템에는 자동 비밀번호 재설정 기능이 없습니다. 동아리 운영진에게 본인의 아이디를 알리고 도움을 요청해주세요.

**Q. 아이디도 기억나지 않아요.**
A. 운영진에게 본인 이름과 기수를 함께 알려주면 확인이 가능합니다.

## 로그인 상태 / 보안

**Q. 한 번 로그인하면 얼마나 유지되나요?**
A. 로그인 정보(토큰)에는 만료 시간이 있습니다. 만료되면 다시 로그인해야 하며, 일부 서비스는 만료 시 자동으로 로그인 페이지로 돌려보냅니다.

**Q. 공용 컴퓨터에서 로그인했어요. 어떻게 해야 하나요?**
A. 가능하면 **시크릿/프라이빗 브라우징 창**에서 로그인하는 것을 추천합니다. 일반 브라우저 창을 사용했다면 사용을 마친 뒤 브라우저의 쿠키 / 사이트 데이터를 지워주세요(보통 "사이트 데이터 / 저장된 비밀번호 / 쿠키 삭제" 옵션).

**Q. 다른 서비스에서 로그아웃했는데 SSO 페이지에서는 여전히 로그인 상태로 보입니다.**
A. 각 서비스마다 로그인 상태를 별도로 저장합니다. SSO 페이지를 직접 방문해 로그아웃이 필요한 경우, 브라우저의 사이트 데이터(쿠키)를 삭제하는 것이 가장 확실한 방법입니다.

## 그 외

**Q. 화면에 영문 / 숫자로 된 에러 코드가 보입니다.**
A. 화면에 표시된 코드와 메시지를 함께 캡처해 운영진에게 전달해주세요. 자세한 코드 의미는 [개발자 가이드의 에러 코드](../developers/error-codes)에 정리되어 있습니다.

**Q. 모바일 앱에서 로그인하다 흰 화면에서 멈췄어요.**
A. 앱의 외부 브라우저 / 웹뷰 설정이 영향을 줄 수 있습니다. 다른 네트워크(예: 와이파이 ↔ 셀룰러)나 브라우저 앱으로 시도해보고, 그래도 안 되면 어떤 단계에서 멈췄는지 운영진에게 알려주세요.
