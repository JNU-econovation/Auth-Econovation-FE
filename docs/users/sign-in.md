# 로그인

에코노베이션 SSO 로그인 페이지는 다음 주소에서 접근합니다.

```
https://auth.econovation.kr
```

대부분의 경우 동아리에서 운영하는 다른 서비스에서 **"로그인" 버튼**을 누르면 자동으로 이 페이지로 이동하게 됩니다. 로그인이 완료되면 다시 원래 사용하던 서비스로 돌아가도록 설계되어 있습니다.

## 입력 항목

- **아이디**: 회원가입 시 사용한 영문 / 숫자 아이디
- **비밀번호**: 회원가입 시 사용한 비밀번호

두 값을 입력한 뒤 로그인 버튼을 누르면 인증이 진행됩니다.

## 로그인 성공 시

- 로그인 정보(액세스 토큰)가 브라우저에 저장됩니다.
- 원래 사용하던 서비스로 자동 이동합니다(이동할 주소는 그 서비스에서 결정합니다).
- 모바일 앱에서 진입한 경우 앱으로 다시 돌아갑니다.

## 로그인 실패 시 안내 메시지

| 화면 메시지 | 의미 / 해결 |
| --- | --- |
| ID 또는 비밀번호가 일치하지 않습니다 | 아이디와 비밀번호를 다시 확인해주세요. 대소문자도 정확히 일치해야 합니다. |
| (그 외 메시지) | 서버에서 전달된 메시지가 그대로 표시됩니다. 메시지 전체를 캡처해 운영진에게 문의하면 가장 빠릅니다. |

## 로그인이 계속 안 될 때

1. **아이디 / 비밀번호 재확인**: 의외로 자판 한영 전환이나 Caps Lock이 원인인 경우가 많습니다.
2. **다른 브라우저 / 시크릿 창에서 시도**: 브라우저에 남은 오래된 세션이 영향을 줄 수 있습니다.
3. **이미 가입했는지 헷갈린다면**: [회원가입](./sign-up) 페이지에서 "이미 존재하는 계정입니다" 메시지가 뜨면 가입된 계정입니다.
4. **그래도 안 된다면**: 동아리 운영진에게 본인의 아이디와 화면 메시지를 전달해주세요.

> 비밀번호 자동 재설정 기능은 **현재 제공되지 않습니다**. 비밀번호를 분실한 경우 운영진에게 직접 문의해야 합니다.

## "유효하지 않은 리다이렉트 URL입니다" 안내가 보일 때

로그인 자체는 정상적으로 완료되었지만, 원래 사용하던 서비스로 돌아가는 주소(redirect-url)에 문제가 있을 때 표시됩니다.

이 메시지가 보인다면 사용자가 직접 해결하기는 어렵습니다. **원래 사용하던 서비스의 운영자/개발자**에게 "auth.econovation.kr 로그인 후 리다이렉트 URL 오류"라고 전달해주세요. 자세한 기술적 원인은 [개발자 가이드의 SSO 연동](../developers/sso-integration#redirect-url-검증-규칙)에 정리되어 있습니다.
