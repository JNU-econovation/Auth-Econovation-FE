# 사용자 가이드

이 페이지는 에코노베이션 동아리에서 운영하는 서비스에 **하나의 계정으로 로그인**하려는 회원을 위한 안내입니다.

> 에코노베이션은 **통합 인증(SSO)** 을 사용합니다. 한 번 가입하면 동아리에서 운영하는 여러 서비스에 같은 ID/비밀번호로 로그인할 수 있습니다.

## 빠른 안내

- **처음 가입한다면** → [회원가입](./sign-up) 페이지를 따라 진행하세요.
- **이미 계정이 있다면** → [로그인](./sign-in) 페이지를 참고하세요.
- **소셜 로그인이나 기존 계정 연결 안내를 받았다면** → [기존 계정 연결](./account-linking) 페이지를 참고하세요.
- **로그인이 안 되거나 문제가 생긴다면** → [자주 묻는 질문](./faq)을 먼저 확인하세요.

## 어디서 로그인하나요?

| 페이지 | 주소 |
| --- | --- |
| 로그인 | `https://auth.econovation.kr` |
| 회원가입 | `https://auth.econovation.kr/sign-in` |

> 보통은 동아리에서 사용하는 다른 서비스(예: 활동 관리 페이지)에서 "로그인" 버튼을 누르면 자동으로 위 페이지로 이동합니다.

## 계정에 문제가 있나요?

본 사이트에는 비밀번호 자동 찾기/재설정 기능이 **아직 제공되지 않습니다**. 비밀번호를 잊었거나 계정을 사용할 수 없는 상태라면 동아리 운영진에게 문의해주세요. 자세한 내용은 [FAQ](./faq)를 확인하세요.
