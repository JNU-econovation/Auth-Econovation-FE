# 회원가입

회원가입은 다음 주소에서 진행합니다.

```
https://auth.econovation.kr/sign-in
```

> URL의 `sign-in`은 "회원가입(sign-up)이 시작되는 화면"의 경로이지 "로그인"이 아닙니다. 헷갈리지 않도록 주의해주세요. 로그인 페이지 하단의 **"회원가입하기"** 링크를 눌러도 같은 화면으로 이동합니다.

## 입력 항목

| 필드 | 입력 규칙 |
| --- | --- |
| 이름 | **한글만** 입력 가능, **최대 5자** |
| 아이디 | **영문 / 숫자만**, **3자 이상 19자 이하** |
| 비밀번호 | 영문 / 숫자 / 특수문자 사용, **8\~20자**, **영문 · 숫자 · 특수기호를 각각 1개 이상** 포함 |
| 비밀번호 확인 | 위 비밀번호와 **완전히 동일**해야 합니다 |
| 기수 | 정수 **1\~99** 사이 |
| 활동 상태 | 아래 표 참고 |

### 비밀번호 상세 규칙

비밀번호 입력 시 다음 순서대로 실시간 검증이 진행됩니다.

1. 영문 · 숫자 · 특수문자 외의 문자가 포함되어 있지 않은가
2. 길이가 8자 이상 20자 이하인가
3. 영문 · 숫자 · 특수기호가 각각 1개 이상 포함되어 있는가

조건을 만족하지 않으면 다음과 같은 안내 문구가 표시됩니다.

- `비밀번호는 영문, 숫자, 특수문자만 입력할 수 있습니다.`
- `비밀번호는 8~20자여야 합니다.`
- `비밀번호는 영문, 숫자, 특수기호를 각각 1개 이상 포함해야 합니다.`

### 활동 상태

| 값 | 의미 |
| --- | --- |
| 활동 회원 | 현재 동아리에서 활동 중인 회원 |
| 수료 회원 | 수료한 회원 |
| 휴면 회원 | 활동을 잠시 쉬고 있는 회원 |
| OB 회원 | 졸업 / 장기 활동 종료 회원 |

> 본인의 활동 상태를 모르겠다면 동아리 운영진에게 확인 후 선택해주세요.

## 가입 직후 동작

회원가입이 정상적으로 완료되면 다음과 같이 동작합니다.

- 자동으로 로그인이 처리됩니다.
- 로그인 정보(액세스 토큰)가 브라우저에 저장됩니다.
- SSO 메인 페이지(`https://auth.econovation.kr`)로 이동합니다.

이후 동아리에서 운영하는 다른 서비스에서 자동으로 로그인된 상태로 보일 수 있습니다.

## 흔한 회원가입 실패

| 화면에 나오는 메시지 | 의미 / 해결 |
| --- | --- |
| 이름이 유효하지 않습니다. | 한글이 아닌 문자가 섞였거나 빈 값. |
| 아이디가 유효하지 않습니다. | 영문 / 숫자가 아닌 문자가 섞였거나 길이가 맞지 않음. |
| 이미 사용 중인 아이디입니다. | 다른 아이디를 사용해주세요. |
| 비밀번호가 유효하지 않습니다. | 위 비밀번호 규칙을 다시 확인해주세요. |
| 기수가 유효하지 않습니다. | 1~99 사이의 정수만 가능합니다. |
| 이미 존재하는 계정입니다. | 이미 가입한 적이 있는 계정입니다. [로그인](./sign-in) 페이지로 이동해주세요. |

> 그 외의 메시지가 표시된다면 그 문구를 그대로 동아리 운영진에게 전달하면 가장 빠르게 도움받을 수 있습니다.
