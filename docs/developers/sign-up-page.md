# 회원가입 페이지

회원가입 페이지는 SSO 도메인에서 직접 제공됩니다. 외부 서비스에서 회원가입이 필요한 사용자에게 다음 URL을 제공하세요.

```
https://auth.econovation.kr/sign-in
```

- 로그인 페이지 하단의 **"회원가입하기"** 링크로도 접근할 수 있습니다.
- 회원가입 성공 시 `accessToken`이 `localStorage`에 저장된 뒤 SSO 메인(`/`)으로 이동합니다.

## `code` 파라미터(기존 계정 연결)

회원가입 페이지는 선택적으로 `code` 쿼리 파라미터를 받습니다. 이는 **기존 회원을 새 계정(예: 소셜 로그인 제공자)과 연결**할 때 사용되는 SSO 인증 코드입니다.

```
https://auth.econovation.kr/sign-in?code=<sso-auth-code>
```

`code`가 존재하면 회원가입 API 호출 시 쿼리스트링(`?code=...`)으로 함께 전송되어 백엔드에서 기존 계정 연결을 수행합니다. 일반 회원가입에서는 생략합니다.

## 입력 필드 검증 규칙

| 필드 | 규칙 |
| --- | --- |
| 이름 | 한글만 입력 가능 (가-힣, ㄱ-ㅎ, ㅏ-ㅣ), 최대 5자 |
| 아이디 | 영문/숫자만, 3~19자 |
| 비밀번호 | ASCII printable 문자, 8~20자, 영문 1개 이상 + 숫자 1개 이상 + 특수기호 1개 이상 |
| 비밀번호 확인 | 비밀번호와 정확히 일치 |
| 기수 | 정수, 1~99 |
| 활동 상태 | `am`, `cm`, `rm`, `ob` 중 선택 |

검증 순서(비밀번호 기준): **빈 문자열 체크 → 허용 문자 → 길이 → 조합 조건**.

## 활동 상태 값

| 값 | 설명 |
| --- | --- |
| `am` | 활동 회원 (Active Member) |
| `cm` | 수료 회원 (Completed Member) |
| `rm` | 휴면 회원 (Rest Member) |
| `ob` | OB 회원 |

## 회원가입 에러 코드

| 코드 | 필드 | 메시지 |
| --- | --- | --- |
| `4100` | `name` | 이름이 유효하지 않습니다 |
| `4101` | `id` | 아이디가 유효하지 않습니다 |
| `4102` | `id` | 이미 사용 중인 아이디입니다 |
| `4103` | `password` | 비밀번호가 유효하지 않습니다 |
| `4104` | `generation` | 기수가 유효하지 않습니다 |
| `4105` | `name` | 이름은 필수 항목입니다 |
| `4106` | `id` | 아이디는 필수 항목입니다 |
| `4107` | `password` | 비밀번호는 필수 항목입니다 |
| `4108` | `generation` | 기수는 필수 항목입니다 |
| `4109` | `activeStatus` | 활동 상태는 필수 항목입니다 |
| `4009` | `id` | 이미 존재하는 계정입니다 |
