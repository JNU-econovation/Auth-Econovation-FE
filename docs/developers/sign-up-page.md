# 회원가입 페이지

회원가입 페이지는 SSO 도메인에서 직접 제공됩니다. 외부 서비스에서 회원가입이 필요한 사용자에게 다음 URL을 제공하세요.

```
https://auth.econovation.kr/sign-in
```

- 로그인 페이지 하단의 **"회원가입하기"** 링크로도 접근할 수 있습니다.
- **회원가입 성공 시 토큰은 발급되지 않습니다.** 가입 후 로그인 페이지(`/`)로 이동하며, 가입한 계정으로 다시 로그인해야 합니다. (SSO 쿼리 파라미터는 보존됩니다.)

## `code` 파라미터(기존 계정 연결)

회원가입 페이지는 선택적으로 `code` 쿼리 파라미터를 받습니다. 이는 **기존 회원을 새 계정(예: 소셜 로그인 제공자)과 연결**할 때 사용되는 SSO 인증 코드입니다.

```
https://auth.econovation.kr/sign-in?code=<sso-auth-code>
```

`code`가 존재하면 회원가입 API 호출 시 쿼리스트링(`?code=...`)으로 함께 전송되어 백엔드에서 기존 계정 연결을 수행합니다. 일반 회원가입에서는 생략합니다.

## 입력 필드 검증 규칙

| 필드 | 규칙 |
| --- | --- |
| 이름 | 1~50자 (문자셋 제한 없음) |
| 아이디 | 영문/숫자/`-`, `_`, `.` 조합, 3~19자 |
| 비밀번호 | ASCII printable 문자, 8~19자, 영문 1개 이상 + 숫자 1개 이상 + 특수기호 1개 이상 |
| 비밀번호 확인 | 비밀번호와 정확히 일치 |
| 기수 | 정수, 1~99 |
| 활동 상태 | `AM`, `RM`, `CM`, `OB` 중 선택 |

검증 순서(비밀번호 기준): **빈 문자열 체크 → 허용 문자 → 길이 → 조합 조건**.

## 활동 상태 값

| 값 | 설명 |
| --- | --- |
| `AM` | 활동 |
| `RM` | 수습 |
| `CM` | 전산 |
| `OB` | 졸업 |

## 회원가입 에러 코드

명세상 회원가입 실패 시 내려오는 `errorCode`는 다음 3가지입니다. 응답 형식과 전체
에러 코드는 [에러 코드](./error-codes) 문서를 참조하세요.

| HTTP | errorCode | 필드 | 메시지 |
| --- | --- | --- | --- |
| 409 | `MEMBER_ALREADY_EXISTS` | `id` | 이미 사용 중인 아이디입니다. |
| 400 | `INVALID_PASSWORD_POLICY` | `password` | 비밀번호 정책을 위반했습니다. |
| 400 | `VALIDATION_FAILED` | (특정 필드 없음) | 서버 응답 `message`를 그대로 사용 |
