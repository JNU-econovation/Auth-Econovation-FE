## Project Overview

auth-econovation은 에코노베이션 서비스들에게 통합 로그인(SSO)을 제공하는 프론트엔드 애플리케이션입니다.
OAuth2.0 Provider와 유사한 방식으로 동작하며, 사용자가 한 번 로그인하면 연결된 모든 서비스에서 동일한 계정으로 인증됩니다.

**배포된 공식 문서 관련 정보가 필요하다면 `docs-knowledge` skills를 참조하세요.**
